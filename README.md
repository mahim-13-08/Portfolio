## Key Features

- **Zero-Dependency Architecture**: 100% Vanilla HTML5, CSS3, and ES6+ JavaScript. Ultra-fast loading with near-instant First Contentful Paint (FCP) and optimal Lighthouse scores.
- **Simone Signature Watermark Headings**: Oversized low-opacity typography layers paired with crisp foreground titles and accent underline bars.
- **Dynamic Typing Animation**: Realistic typing and deleting loop in the hero section cycling through developer roles.
- **Live Theme Customizer**: Floating widget allowing visitors to switch between 5 accent color palettes (Spring Green, Electric Violet, Ocean Cyan, Amber Gold, Crimson Red) in real-time, with localStorage persistence.
- **Interactive Project Showcase**:
  - Filter projects by category (*All, Java & OOP, MERN & Web, Database & SQL*).
  - Detailed modal case studies with full architecture descriptions, tech tags, and direct GitHub repository links.
- **1-Click Google Calendar Scheduling**: Deep-links to Google Calendar template API with pre-populated event details, automated Google Meet video links, and automatic guest invitations.
- **Direct Gmail Web Composer**: Contact forms and email links launch directly in Gmail on the web without triggering OS mail client popups.
- **Responsive Dual-Navigation**:
  - **Desktop (>= 992px)**: Fixed left vertical sidebar with profile headshot, navigation links, and social icons.
  - **Mobile (< 992px)**: Sticky top navigation bar with mini avatar and an off-canvas drawer navigation menu.
- **Accessibility & UX**: Strict semantic markup, ARIA attributes, keyboard accessibility (Escape key to close modals), smooth scrolling, and scroll reading progress bar.

## Tech Stack

| Layer | Technology | Description |
| :--- | :--- | :--- |
| **Markup** | Semantic HTML5 | Structured layout using <header>, <main>, <section>, <article>, <aside>, and <footer> tags. |
| **Styling** | Modern CSS3 (Vanilla) | Custom 18-part design system using CSS Variables (--accent, --bg-dark), CSS Grid, Flexbox, clamp() fluid typography, and glassmorphism with ackdrop-filter. |
| **Scripting** | Vanilla JavaScript (ES6+) | Native DOM manipulation, IntersectionObserver for ScrollSpy, event delegation, and localStorage API. |
| **Typography** | Google Fonts | **Poppins** for bold headings; **Rubik** for high-legibility body paragraphs. |
| **Graphics** | SVG & Retina JPG | Lossless custom SVG vector mockups and 800x800 high-resolution profile headshot. |
| **Calendar** | Google Calendar URL Engine | Direct event invitation integration via universal template URL. |
